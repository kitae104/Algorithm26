# 전체 교육과정 — 13개 강좌 연결 구조

초보 개발자를 위한 필수 알고리즘은 **누적형 학습 구조**로 설계되었다.
각 강의는 이전 강의에서 배운 도구를 반복 사용하며, 새 도구를 하나씩 얹는다.

## 전체 흐름

```text
1강 알고리즘과 복잡도
    ↓ 입력·처리·출력, 연산 카운터, Big-O
2강 배열과 리스트
    ↓ 순회, 누적, 조건 검색, 빈도
3강 완전 탐색·문자열·해시
    ↓ 중첩 반복문, HashMap/HashSet
4강 정렬
    ↓ 정렬된 배열, Comparator
5강 탐색
    ↓ 이진 탐색 (절반 버리기)
6강 스택과 큐
    ↓ LIFO/FIFO, 우선순위 큐 기초
7강 재귀와 백트래킹
    ↓ 호출 스택, 선택-진행-취소, 방문 관리
8강 트리
    ↓ 재귀 순회, 레벨 순회(큐)
9강 그래프와 DFS·BFS
    ↓ 인접 리스트, 방문 배열, 스택/큐 탐색
10강 그리디
    ↓ 정렬 + 최선 선택, 우선순위 큐
11강 동적 계획법
    ↓ 점화식, DP 테이블 (재귀의 중복 계산 해결)
12강 최단 경로
    ↓ 그래프 + 그리디 + 거리 갱신(점화식) + 우선순위 큐
13강 종합 프로젝트
    → 전체 결합: 정렬 + 탐색 + 해시 + 예외 처리
```

## 강좌별 선수 학습 관계

| 강의 | 직접 선수 강의 | 다시 사용하는 도구 |
|------|---------------|-------------------|
| 1강 알고리즘 기초 | (없음) | Java 기본 문법 |
| 2강 배열과 리스트 | 1강 | 입력·처리·출력, 반복 횟수 세기 |
| 3강 완전 탐색·문자열·해시 | 1·2강 | 배열 순회, 조건 검색, 복잡도 비교 |
| 4강 정렬 | 2·3강 | 최솟값 찾기, 중첩 반복문, 연산 카운터 |
| 5강 탐색 | 2·4강 | 정렬된 배열, 인덱스, 조기 중단 |
| 6강 스택과 큐 | 2·3강 | 배열/리스트, 문자열 순회 |
| 7강 재귀와 백트래킹 | 3·6강 | 완전 탐색, 스택(호출 스택), 방문 관리 |
| 8강 트리 | 5·6·7강 | 재귀, 큐(레벨 순회), 절반 버리기(BST) |
| 9강 그래프와 DFS·BFS | 6·7·8강 | 스택/큐, 재귀, 트리 순회, 방문 배열 |
| 10강 그리디 | 4·6강 | 정렬, Comparator, 우선순위 큐 |
| 11강 동적 계획법 | 2·7·10강 | 배열(테이블), 재귀, 그리디와의 차이 |
| 12강 최단 경로 | 9·10·11강 | 그래프 표현, BFS, 그리디 선택, 거리 갱신 점화식 |
| 13강 종합 프로젝트 | 1~12강 전체 | 요구사항 → 자료구조/알고리즘 선택 결정 |

## 강의 공통 구성 (20개 섹션)

모든 강의 페이지는 같은 20개 섹션으로 구성된다:
강의 소개 → 학습 목표 → 선수 지식 → 실제 문제 상황 → 사람이 직접 해결
→ 핵심 개념 → 단계별 동작 과정(시각화) → 의사코드 → 점진적 Java 구현 → 완성 코드
→ 실행 과정 추적 → 오류 찾기 → 복잡도 분석 → 따라 하기 실습 → 실제 데이터 응용
→ 최종 프로그램 문제 → 정답과 해설 → 확인 퀴즈 → 핵심 정리 → 다음 강의 연결.

## 학습 방법 권장 순서

1. 선수 지식 섹션으로 필요한 도구를 점검한다.
2. 문제 상황을 읽고, 사람이 직접 해결 단계의 질문에 먼저 답해 본다.
3. 시각화를 이전/다음 버튼으로 조작하며 알고리즘의 상태 변화를 관찰한다.
4. 점진적 구현 코드를 단계마다 복사·실행하며 이전 단계와의 차이를 확인한다.
5. 실습 → 최종 프로그램 문제를 직접 구현한다 (정답은 막힌 뒤에만 연다).
6. 확인 퀴즈 정답률 70% 이상으로 강의를 완료 처리한다.
