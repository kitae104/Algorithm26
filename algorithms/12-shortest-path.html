최단 경로 알고리즘

Shortest Path Algorithms

그래프 중급 Java 17+

지도 앱은 어떻게 "가장 빠른 길"을 몇 초 만에 찾아낼까요? 이번 강의에서는 9강의 그래프, 10강의 그리디 선택, 11강의 점화식이 하나로 합쳐진 다익스트라(Dijkstra) 알고리즘을 배웁니다. 무가중치 BFS에서 출발해, 가중치가 생기면 왜 BFS가 실패하는지 확인하고, 거리 배열과 완화(relaxation)로 다익스트라를 단계적으로 완성합니다.

이 강의의 목차

    01강의 소개

    9강에서 우리는 그래프를 인접 리스트로 표현하고 BFS로 "가장 적은 간선 수"의 경로를 찾았습니다. 그런데 현실의 길에는 가중치가 붙어 있습니다. 같은 한 칸이라도 3분 걸리는 길과 7분 걸리는 길은 다릅니다. 간선 수가 아니라 가중치의 합이 가장 작은 경로를 찾는 문제, 이것이 오늘의 주제인 최단 경로 문제입니다.

    이번 강의는 지금까지 배운 도구가 총출동하는 강의입니다. 그래프 표현(9강) 위에서, 그리디 선택(10강)으로 다음 정점을 확정하고, 점화식 모양의 거리 갱신(11강)으로 거리를 좁혀 가며, 마지막에는 우선순위 큐(6·10강)로 속도까지 끌어올립니다. 무가중치 BFS → BFS의 실패 → 거리 배열과 완화 → 배열 버전 다익스트라 → 우선순위 큐 버전 순서로, 완성 코드를 향해 한 단계씩 나아갑니다.

    05사람이 직접 해결해 보기

    코드를 쓰기 전에, 위의 캠퍼스 지도를 손으로 풀어 봅니다. 종이에 정점 6개를 그리고, 각 정점 옆에 "지금까지 알아낸 A에서의 최소 시간"을 연필로 적으세요. 처음에는 A만 0분이고, 나머지는 모름(∞)입니다.

    STEP 1

    A(0분)에서 한 번에 갈 수 있는 곳을 적습니다: B는 3분, C는 7분. 이제 후보는 B(3분), C(7분)입니다.

    질문: 이 중 "이 값이 곧 최종 답"이라고 지금 확신할 수 있는 정점은 어디일까요?

    B(3분)입니다. 다른 어떤 길로 B에 가더라도 일단 C(7분)나 그 너머를 지나야 하는데, 모든 길의 시간이 0 이상이므로 3분보다 짧아질 수 없습니다. "미확정 후보 중 가장 가까운 곳은 그대로 확정해도 된다" — 이것이 다익스트라의 그리디 선택입니다(10강).

    STEP 2

    B(3분)를 확정하고, B에서 갈 수 있는 곳의 후보를 갱신합니다. C: A에서 바로 가면 7분이지만 B를 거치면 3 + 2 = 5분 → 7을 지우고 5로 고칩니다. D: 3 + 6 = 9분 → 새 후보로 적습니다.

    질문: C의 값을 7에서 5로 "고쳐 쓴" 이 행동을 일반 규칙으로 표현하면 어떻게 될까요?

    dist[C] = min(dist[C], dist[B] + 시간(B,C)) = min(7, 3+2) = 5. "지금 확정된 정점을 거쳐 가면 더 짧아지는지 확인하고, 짧아지면 갱신한다" — 이 규칙을 완화(relaxation)라고 부릅니다. 11강 점화식과 같은 모양입니다.

    STEP 3

    같은 일을 반복합니다. 후보 중 최소인 C(5분)를 확정 → E 후보 5 + 8 = 13분. 다음 최소인 D(9분)를 확정 → E는 9 + 1 = 10분으로 갱신, F는 9 + 5 = 14분. 다음 최소인 E(10분)를 확정 → F는 10 + 3 = 13분으로 갱신. 마지막으로 F(13분)를 확정하면 끝입니다.

    질문: 확정된 순서(A, B, C, D, E, F)와 확정된 거리(0, 3, 5, 9, 10, 13) 사이에 어떤 규칙이 보이나요?

    거리가 작은 순서대로 확정됩니다. BFS가 "간선 수가 적은 층부터" 방문을 확정하듯, 다익스트라는 "총 시간이 짧은 정점부터" 확정합니다. 그래서 다익스트라를 가중치 그래프 위의 BFS라고 부르기도 합니다.

    STEP 4

    최종 결과: A 0분, B 3분, C 5분, D 9분, E 10분, F 13분. 그런데 이용자에게는 "13분"이라는 숫자만이 아니라 길 안내도 보여 줘야 합니다.

    질문: 손으로 풀면서 "F까지 가는 실제 경로"를 알아내려면 무엇을 함께 메모해야 했을까요?

    거리를 갱신할 때마다 "어느 정점을 거쳐서 이 값이 되었는지"를 함께 적어야 합니다. F는 E를 거쳐 13분이 되었고, E는 D를, D는 B를, B는 A를 거쳤습니다. 거꾸로 따라가면 A → B → D → E → F. 코드에서는 이 메모가 prev 배열이 됩니다 (경로 복원).

    2. 복습 — 무가중치라면 9강의 BFS로 충분하다

    모든 간선의 가중치가 같다면(예: 전부 1) 최단 경로 = 간선 수가 가장 적은 경로이고, 이것은 9강에서 배운 BFS가 정확히 찾아 줍니다. 캠퍼스 그래프에서 가중치를 무시하고 BFS를 돌려 봅시다.

    Java BfsShortestPath.java 
    import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Queue;

public class BfsShortestPath {

    /** 간선: 도착 정점과 가중치. BFS는 가중치를 무시한다 — 비교 출력에만 사용한다 */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    static void addEdge(List<List<Edge>> graph, int u, int v, int weight) {
        graph.get(u).add(new Edge(v, weight));
        graph.get(v).add(new Edge(u, weight));
    }

    /** u-v 간선의 가중치를 찾는다 (경로의 이동 시간 합을 계산할 때 사용) */
    static int findWeight(List<List<Edge>> graph, int u, int v) {
        for (Edge e : graph.get(u)) {
            if (e.to == v) {
                return e.weight;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};
        int n = names.length;

        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        addEdge(graph, 0, 1, 3);  // A-B
        addEdge(graph, 0, 2, 7);  // A-C
        addEdge(graph, 1, 2, 2);  // B-C
        addEdge(graph, 1, 3, 6);  // B-D
        addEdge(graph, 2, 3, 4);  // C-D
        addEdge(graph, 2, 4, 8);  // C-E
        addEdge(graph, 3, 4, 1);  // D-E
        addEdge(graph, 3, 5, 5);  // D-F
        addEdge(graph, 4, 5, 3);  // E-F

        // 9강에서 배운 BFS 최단 거리: 방문 순서대로 "간선 수"가 확정된다
        int start = 0;
        int[] hops = new int[n];      // 최소 간선 수 (-1 = 아직 방문 안 함)
        int[] prev = new int[n];      // 경로 복원용 직전 정점
        Arrays.fill(hops, -1);
        Arrays.fill(prev, -1);

        Queue<Integer> queue = new ArrayDeque<>();
        hops[start] = 0;
        queue.add(start);

        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (Edge e : graph.get(u)) {
                if (hops[e.to] == -1) {          // 처음 도착한 정점만
                    hops[e.to] = hops[u] + 1;    // 간선 수 = 직전 정점 + 1
                    prev[e.to] = u;
                    queue.add(e.to);
                }
            }
        }

        System.out.println("[BFS] A에서 각 정점까지의 최소 간선 수:");
        for (int v = 0; v < n; v++) {
            System.out.println("  A -> " + names[v] + " : 간선 " + hops[v] + "개");
        }

        // BFS가 찾은 A -> C 경로를 복원하고, 그 경로의 "이동 시간 합"을 계산해 본다
        int target = 2;   // C
        StringBuilder path = new StringBuilder(names[target]);
        int timeSum = 0;
        int v = target;
        while (prev[v] != -1) {
            timeSum += findWeight(graph, prev[v], v);
            v = prev[v];
            path.insert(0, names[v] + " -> ");
        }

        System.out.println();
        System.out.println("BFS가 찾은 A -> C 경로: " + path
                + " (간선 " + hops[target] + "개, 이동 시간 합 " + timeSum + "분)");
        System.out.println("하지만 A -> B -> C 로 가면 3 + 2 = 5분이다!");
        System.out.println("BFS는 간선 수가 가장 적은 경로를 찾을 뿐,");
        System.out.println("가중치(이동 시간)의 합이 최소인 경로는 보장하지 못한다.");
    }
}

    3. 가중치가 붙는 순간 BFS가 무너진다

    출력이 보여 주는 실패 장면을 정리하면 이렇습니다. BFS는 C를 "A에서 간선 1개"로 확정하지만, 그 길은 7분짜리입니다. 간선 2개를 건너는 A → B → C는 3 + 2 = 5분으로 더 빠릅니다. BFS의 확정 논리는 "먼저 도착한 것이 가장 가깝다"인데, 가중치가 다르면 "먼저 발견"과 "가장 빠름"이 어긋나기 때문입니다. 그래서 확정 기준을 간선 수가 아니라 지금까지의 가중치 합으로 바꿔야 합니다.

    4. 거리 배열 — "지금까지 알아낸 최선"의 기록

    출발점에서 각 정점까지 지금까지 알아낸 가장 짧은 거리를 배열 dist에 기록합니다. 처음에는 출발점만 0이고 나머지는 전부 ∞(모른다)입니다. 코드에서는 ∞를 Integer.MAX_VALUE로 표현하는데, 여기에 가중치를 더하면 오버플로로 음수가 되므로 ∞인 값에는 절대 덧셈을 하면 안 됩니다 (구현 2단계에서 직접 확인합니다).

    5. 완화(relaxation) — 11강 점화식의 재등장

    정점 u까지의 거리 dist[u]가 확정되었을 때, u의 이웃 v에 대해 "u를 거쳐 가면 더 짧아지는가?"를 검사하고 갱신하는 것이 완화입니다.

    완화 규칙 (오늘의 점화식)

    dist[v] = min(dist[v], dist[u] + w(u, v))

    11강에서 DP 테이블을 dp[i] = min(dp[i], dp[j] + cost)로 갱신하던 것과 완전히 같은 모양입니다. "더 좋은 후보를 발견하면 표의 값을 고쳐 쓴다" — 그 패턴이 그래프 위로 옮겨 온 것뿐입니다.

    6. 그리디 확정 — 가장 가까운 미확정 정점은 번복되지 않는다

    손 풀이 STEP 1에서 확인했듯, 미확정 정점 중 dist가 가장 작은 정점 u는 그 값이 곧 최종 답입니다. 이유를 한 번 더 정확히 말하면: u에 다른 경로로 도달하려면 반드시 어떤 미확정 정점 x를 거쳐야 하는데, dist[x] ≥ dist[u]이고 모든 가중치가 0 이상이므로 돌아가는 경로는 절대 dist[u]보다 짧아질 수 없습니다. 10강의 그리디처럼 "한 번 한 선택을 번복하지 않아도 되는" 구조가 성립하는 것입니다.

    음수 가중치가 있으면 다익스트라를 쓸 수 없다

    위 논리는 "가중치 ≥ 0"에 기대고 있습니다. 만약 어떤 간선의 가중치가 음수라면, 멀리 돌아가는 경로가 나중에 합계를 오히려 줄일 수 있어 이미 확정한 거리가 틀릴 수 있습니다. 예: A→B 5, A→C 10, C→B -8이면 다익스트라는 B를 5로 확정하지만 실제 최단은 10 + (-8) = 2입니다. 음수 가중치 그래프는 벨만-포드(Bellman-Ford) 같은 다른 알고리즘의 영역입니다 — 오늘은 이름만 기억해 두세요.

    7. 우선순위 큐 복습 — "가장 가까운 정점 뽑기"를 빠르게

    "미확정 중 최솟값 뽑기"를 매번 배열 전체를 훑어 찾으면 한 번에 O(V)입니다. 6강과 10강에서 배운 PriorityQueue는 가장 작은 항목을 O(log V)에 꺼내 주는 자료구조였죠. 거리와 정점 번호를 int[]{거리, 정점}으로 묶어 넣고 Comparator.comparingInt(item -> item[0])로 "거리 기준 최소"를 지정하면, poll()이 항상 가장 가까운 후보를 꺼내 줍니다. 단, 같은 정점이 큐에 여러 번 들어갈 수 있으므로(거리가 갱신될 때마다 새로 넣기 때문) 꺼낸 뒤 이미 확정된 정점이면 건너뛰는 처리가 필요합니다 — 완성 코드에서 확인합니다.

    8. 경로 복원 — prev 배열

    완화로 dist[v]를 갱신하는 순간, "v는 u를 거쳐 왔다"를 prev[v] = u로 기록해 둡니다. 목적지에서 prev를 따라 거꾸로 올라가면 출발점까지의 경로가 복원됩니다. 손 풀이 STEP 4에서 F → E → D → B → A로 거슬러 올라간 것과 같은 원리입니다.

    07단계별 동작 과정

    캠퍼스 그래프에서 다익스트라가 진행되는 모습을 단계별로 확인해 봅시다. 다음 단계 ▶ 버튼으로 한 단계씩 진행하세요. 파란색(현재)은 이번 회차에 확정하는 정점, 앰버색(비교 중)은 완화로 거리가 갱신된 정점, 초록색(확정)은 최단 거리가 확정된 정점입니다. 정점 아래 숫자는 현재 dist 값이고, 오른쪽 표에서 같은 값을 함께 볼 수 있습니다. "새 데이터" 버튼을 누르면 출발 정점이 무작위로 바뀝니다.

    시각화 마지막 단계에서 확정 순서가 거리가 작은 순서(A 0 → B 3 → C 5 → D 9 → E 10 → F 13)와 일치함을 확인하세요. 손 풀이(5번 섹션)와 완전히 같은 진행입니다.

    08의사코드

    손 풀이 절차를 언어 중립적인 의사코드로 정리합니다. 먼저 배열 버전, 다음이 우선순위 큐 버전입니다.

    Pseudo 다익스트라 — 배열 버전 
    알고리즘 Dijkstra(graph, start)
    모든 정점 v에 대해 dist[v] ← ∞, visited[v] ← 거짓, prev[v] ← 없음
    dist[start] ← 0

    정점 수만큼 반복:
        u ← 미확정 정점 중 dist가 가장 작은 정점     // 그리디 선택 (10강)
        u가 없으면 반복 종료                         // 남은 정점은 도달 불가
        visited[u] ← 참                              // u의 최단 거리 확정

        u의 모든 간선 (u, v, w)에 대해:
            dist[u] + w < dist[v] 이면:              // 완화 (11강 점화식)
                dist[v] ← dist[u] + w
                prev[v] ← u                          // 경로 복원용 기록

    dist와 prev를 반환한다
    Pseudo 다익스트라 — 우선순위 큐 버전 
    알고리즘 DijkstraPQ(graph, start)
    dist[start] ← 0, 나머지는 ∞
    우선순위 큐 pq에 (0, start)를 넣는다             // 항목 = (거리, 정점)

    pq가 빌 때까지 반복:
        (d, u) ← pq에서 거리가 가장 작은 항목        // O(log V) 꺼내기 (6·10강)
        u가 이미 확정이면 건너뛴다                   // 낡은 항목 무시
        u를 확정한다

        u의 모든 간선 (u, v, w)에 대해:
            d + w < dist[v] 이면:                    // 완화
                dist[v] ← d + w
                prev[v] ← u
                pq에 (dist[v], v)를 넣는다           // 갱신된 새 거리로 넣기

    dist와 prev를 반환한다

    두 버전의 차이는 오직 "미확정 중 최솟값을 어떻게 찾는가"뿐입니다. 배열 버전은 매번 전체를 훑고(O(V)), 큐 버전은 우선순위 큐가 대신 찾아 줍니다(O(log V)). 완화 규칙과 확정 논리는 완전히 같습니다.

    Java Step1WeightedGraph.java 
    import java.util.ArrayList;
import java.util.List;

public class Step1WeightedGraph {

    /** 간선 정보: 도착 정점 번호와 가중치(이동 시간) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    /** 무방향 가중치 간선을 양쪽 인접 리스트에 모두 추가한다 */
    static void addEdge(List<List<Edge>> graph, int u, int v, int weight) {
        graph.get(u).add(new Edge(v, weight));
        graph.get(v).add(new Edge(u, weight));
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};
        int vertexCount = names.length;

        // 정점 수만큼 빈 인접 리스트를 준비한다
        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < vertexCount; i++) {
            graph.add(new ArrayList<>());
        }

        // 간선 9개: (정점, 정점, 가중치 = 이동 시간)
        addEdge(graph, 0, 1, 3);  // A-B
        addEdge(graph, 0, 2, 7);  // A-C
        addEdge(graph, 1, 2, 2);  // B-C
        addEdge(graph, 1, 3, 6);  // B-D
        addEdge(graph, 2, 3, 4);  // C-D
        addEdge(graph, 2, 4, 8);  // C-E
        addEdge(graph, 3, 4, 1);  // D-E
        addEdge(graph, 3, 5, 5);  // D-F
        addEdge(graph, 4, 5, 3);  // E-F

        System.out.println("정점 수: " + vertexCount + ", 간선 수: 9");
        for (int u = 0; u < vertexCount; u++) {
            StringBuilder line = new StringBuilder(names[u] + ":");
            for (Edge e : graph.get(u)) {
                line.append(" (").append(names[e.to]).append(", ").append(e.weight).append(")");
            }
            System.out.println(line);
        }
    }
}

    Java Step3PickClosest.java 
    public class Step3PickClosest {

    /** "아직 도달하는 방법을 모른다"를 나타내는 값 */
    static final int INF = Integer.MAX_VALUE;

    /**
     * 아직 확정되지 않은 정점 중에서 거리가 가장 작은 정점 번호를 찾는다.
     * 전부 확정됐거나 남은 정점이 모두 INF(도달 불가)이면 -1을 반환한다.
     * 2강에서 배운 "최솟값 찾기"에 visited 조건 하나만 얹은 것이다.
     */
    static int pickClosest(int[] dist, boolean[] visited) {
        int minVertex = -1;
        int minDist = INF;
        for (int v = 0; v < dist.length; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                minVertex = v;
            }
        }
        return minVertex;
    }

    /** INF는 ∞ 기호로 바꿔서 보여 준다 */
    static String show(int d) {
        return d == INF ? "∞" : String.valueOf(d);
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};

        // 출발 정점 A를 확정하고, A의 간선(B까지 3, C까지 7)으로 갱신을 마친 직후의 상태
        int[] dist = {0, 3, 7, INF, INF, INF};
        boolean[] visited = {true, false, false, false, false, false};

        System.out.println("현재 거리 배열:");
        for (int v = 0; v < names.length; v++) {
            System.out.println("  dist[" + names[v] + "] = " + show(dist[v])
                    + (visited[v] ? "  (확정)" : ""));
        }

        int next = pickClosest(dist, visited);
        System.out.println();
        System.out.println("미확정 정점 중 거리가 가장 작은 정점: " + names[next]
                + " (거리 " + dist[next] + ")");
        System.out.println("모든 가중치가 0 이상이므로, 어떤 길로 돌아가도 "
                + names[next] + "까지 " + dist[next] + "보다 짧아질 수 없다 -> 확정!");

        // B를 확정 표시하고 한 번 더 뽑으면? (확정된 정점은 건너뛴다)
        visited[next] = true;
        int afterNext = pickClosest(dist, visited);
        System.out.println();
        System.out.println(names[next] + " 확정 후 다시 뽑으면: " + names[afterNext]
                + " (거리 " + dist[afterNext] + ")");
    }
}

    구현 4단계 — 완화를 더해 배열 버전 다익스트라 완성 (11강)

    이제 뽑기(3단계) → 확정 → 완화(11강 점화식)를 정점 수만큼 반복하면 다익스트라가 완성됩니다. 완화가 일어날 때마다 로그를 출력해서 손 풀이 STEP 2~3과 똑같이 진행되는지 확인합니다.

    Java Step4Relax.java 
    import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Step4Relax {

    static final int INF = Integer.MAX_VALUE;

    /** 간선 정보: 도착 정점 번호와 가중치(이동 시간) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    static void addEdge(List<List<Edge>> graph, int u, int v, int weight) {
        graph.get(u).add(new Edge(v, weight));
        graph.get(v).add(new Edge(u, weight));
    }

    /** 미확정 정점 중 거리가 가장 작은 정점 번호. 없으면 -1 (Step3과 동일) */
    static int pickClosest(int[] dist, boolean[] visited) {
        int minVertex = -1;
        int minDist = INF;
        for (int v = 0; v < dist.length; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                minVertex = v;
            }
        }
        return minVertex;
    }

    static String show(int d) {
        return d == INF ? "∞" : String.valueOf(d);
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};
        int n = names.length;

        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        addEdge(graph, 0, 1, 3);  // A-B
        addEdge(graph, 0, 2, 7);  // A-C
        addEdge(graph, 1, 2, 2);  // B-C
        addEdge(graph, 1, 3, 6);  // B-D
        addEdge(graph, 2, 3, 4);  // C-D
        addEdge(graph, 2, 4, 8);  // C-E
        addEdge(graph, 3, 4, 1);  // D-E
        addEdge(graph, 3, 5, 5);  // D-F
        addEdge(graph, 4, 5, 3);  // E-F

        int start = 0;                    // 출발 정점 A
        int[] dist = new int[n];
        boolean[] visited = new boolean[n];
        Arrays.fill(dist, INF);
        dist[start] = 0;

        // 정점 수만큼 반복: 뽑기(그리디) -> 확정 -> 완화(거리 갱신)
        for (int round = 1; round <= n; round++) {
            int u = pickClosest(dist, visited);
            if (u == -1) {
                break;                    // 더 도달할 수 있는 정점이 없다
            }
            visited[u] = true;            // u까지의 최단 거리 확정
            System.out.println(round + "회차 확정: " + names[u] + " (거리 " + dist[u] + ")");

            // u를 거쳐 가면 더 짧아지는 이웃의 거리를 갱신한다 = 완화(relaxation)
            // (pickClosest가 INF인 정점은 뽑지 않으므로 dist[u] + weight는 넘치지 않는다)
            for (Edge e : graph.get(u)) {
                if (dist[u] + e.weight < dist[e.to]) {
                    System.out.println("    완화: dist[" + names[e.to] + "] "
                            + show(dist[e.to]) + " -> " + (dist[u] + e.weight)
                            + "  (" + names[u] + " 경유)");
                    dist[e.to] = dist[u] + e.weight;
                }
            }
        }

        System.out.println();
        System.out.println("A에서 각 정점까지의 최단 거리:");
        for (int v = 0; v < n; v++) {
            System.out.println("  A -> " + names[v] + " : " + show(dist[v]));
        }
    }
}

    10완성 Java 코드

    배열 버전의 pickClosest는 매 회차 배열 전체를 훑습니다(O(V)). 이 부분을 6·10강에서 배운 PriorityQueue로 바꾸고, prev 배열 경로 복원까지 더한 완성본입니다. 큐 항목은 int[]{거리, 정점 번호}이고, 거리가 갱신될 때마다 새 항목을 넣기 때문에 같은 정점이 큐에 여러 번 들어갈 수 있습니다 — 그래서 꺼낸 뒤 visited로 낡은 항목을 건너뛰는 한 줄이 반드시 필요합니다.

    Java DijkstraComplete.java 
    import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;
import java.util.PriorityQueue;

public class DijkstraComplete {

    static final int INF = Integer.MAX_VALUE;

    /** 간선 정보: 도착 정점 번호와 가중치(이동 시간) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    /** 다익스트라 결과: 최단 거리 배열 + 경로 복원용 직전 정점 배열 */
    static class Result {
        int[] dist;
        int[] prev;

        Result(int[] dist, int[] prev) {
            this.dist = dist;
            this.prev = prev;
        }
    }

    static void addEdge(List<List<Edge>> graph, int u, int v, int weight) {
        graph.get(u).add(new Edge(v, weight));
        graph.get(v).add(new Edge(u, weight));
    }

    /**
     * 우선순위 큐 버전 다익스트라.
     * 큐 항목은 {거리, 정점 번호} 배열 — 거리가 작은 항목부터 나온다(10강의 PriorityQueue).
     * pickClosest의 O(V) 훑기를 큐의 O(log V) 꺼내기로 바꾼 것이다.
     */
    static Result dijkstra(List<List<Edge>> graph, int start) {
        int n = graph.size();
        int[] dist = new int[n];
        int[] prev = new int[n];
        boolean[] visited = new boolean[n];
        Arrays.fill(dist, INF);
        Arrays.fill(prev, -1);
        dist[start] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(item -> item[0]));
        pq.add(new int[]{0, start});

        while (!pq.isEmpty()) {
            int[] item = pq.poll();      // 미확정 정점 중 거리가 가장 작은 항목
            int d = item[0];
            int u = item[1];
            if (visited[u]) {
                continue;                // 이미 확정된 정점의 낡은 항목은 건너뛴다
            }
            visited[u] = true;           // u까지의 최단 거리 확정

            for (Edge e : graph.get(u)) {
                int newDist = d + e.weight;
                if (newDist < dist[e.to]) {              // 완화 조건
                    dist[e.to] = newDist;
                    prev[e.to] = u;                      // 경로 복원용: 어디서 왔는지 기록
                    pq.add(new int[]{newDist, e.to});    // 갱신된 "새" 거리로 넣는다
                }
            }
        }
        return new Result(dist, prev);
    }

    /** prev 배열을 도착점에서 출발점까지 거슬러 올라가 경로 문자열을 만든다 */
    static String buildPath(int[] prev, String[] names, int end) {
        StringBuilder path = new StringBuilder(names[end]);
        int v = end;
        while (prev[v] != -1) {
            v = prev[v];
            path.insert(0, names[v] + " -> ");
        }
        return path.toString();
    }

    static String show(int d) {
        return d == INF ? "∞" : String.valueOf(d);
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};
        int n = names.length;

        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }
        addEdge(graph, 0, 1, 3);  // A-B
        addEdge(graph, 0, 2, 7);  // A-C
        addEdge(graph, 1, 2, 2);  // B-C
        addEdge(graph, 1, 3, 6);  // B-D
        addEdge(graph, 2, 3, 4);  // C-D
        addEdge(graph, 2, 4, 8);  // C-E
        addEdge(graph, 3, 4, 1);  // D-E
        addEdge(graph, 3, 5, 5);  // D-F
        addEdge(graph, 4, 5, 3);  // E-F

        int start = 0;
        Result result = dijkstra(graph, start);

        System.out.println("출발 정점: " + names[start]);
        System.out.println("도착 | 최단 거리 | 경로");
        System.out.println("-----+----------+------------------------------");
        for (int v = 0; v < n; v++) {
            System.out.printf("   %s | %8s | %s%n",
                    names[v], show(result.dist[v]), buildPath(result.prev, names, v));
        }
    }
}

    Java DijkstraTrace.java 
    import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class DijkstraTrace {

    static final int INF = Integer.MAX_VALUE;

    /** 간선 정보: 도착 정점 번호와 가중치(이동 시간) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    static void addEdge(List<List<Edge>> graph, int u, int v, int weight) {
        graph.get(u).add(new Edge(v, weight));
        graph.get(v).add(new Edge(u, weight));
    }

    static int pickClosest(int[] dist, boolean[] visited) {
        int minVertex = -1;
        int minDist = INF;
        for (int v = 0; v < dist.length; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                minVertex = v;
            }
        }
        return minVertex;

    static void printRow(String label, String confirmed, int[] dist) {
        StringBuilder row = new StringBuilder();
        row.append(String.format("%-4s | %-4s |", label, confirmed));
        for (int d : dist) {
            row.append(String.format(" %4s", show(d)));
        }
        System.out.println(row);
    }

    public static void main(String[] args) {
        String[] names = {"A", "B", "C", "D", "E", "F"};
        int n = names.length;

        List<List<Edge>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) {

        addEdge(graph, 1, 2, 2);  // B-C
        addEdge(graph, 1, 3, 6);  // B-D
        addEdge(graph, 2, 3, 4);  // C-D
        addEdge(graph, 2, 4, 8);  // C-E
        addEdge(graph, 3, 4, 1);  // D-E
        addEdge(graph, 3, 5, 5);  // D-F
        addEdge(graph, 4, 5, 3);  // E-F

        int start = 0;
        int[] dist = new int[n];
        boolean[] visited = new boolean[n];
        Arrays.fill(dist, INF);
        dist[start] = 0;

        System.out.println("A 출발 다익스트라 — 회차별 거리 배열의 변화");
        StringBuilder header = new StringBuilder("회차 | 확정 |");
        for (String name : names) {
            header.append(String.format(" %4s", name));
        }
        System.out.println(header);
        System.out.println("-----+------+------------------------------");

    }

    A에서 각 정점까지의 최단 거리:
  A -> A : 0
  A -> B : 3
  A -> C : 7
  A -> D : 9
  A -> E : 15
  A -> F : 14

    발생하는 문제: C는 7(정답 5), E는 15(정답 10), F는 14(정답 13) — 세 정점이 모두 틀립니다.

    원인: A를 처리할 때 C가 7로 "처음 발견"되면서 즉시 확정됩니다. 그 뒤 B를 거치는 5분 경로를 발견해도 visited[C]가 이미 참이라 무시됩니다. 핵심 개념 3에서 본 BFS의 실패가 그대로 재현된 것입니다. 무가중치 BFS에서는 "처음 발견 = 최단"이 성립하지만, 가중치 그래프에서는 "큐에서 가장 작은 거리로 꺼내지는 순간"에만 확정할 수 있습니다.

    수정 방법: 확정을 꺼낼 때로 미루고, 완화 조건으로 갱신하며, 낡은 항목은 건너뜁니다.

    while (!pq.isEmpty()) {
    int[] item = pq.poll();
    int d = item[0];
    int u = item[1];
    if (visited[u]) continue;    // 꺼낼 때 확인하고
    visited[u] = true;           // 꺼낼 때 확정한다
    for (Edge e : graph.get(u)) {
        int newDist = d + e.weight;
        if (newDist < dist[e.to]) {          // 완화 조건으로 갱신
            dist[e.to] = newDist;
            pq.add(new int[]{newDist, e.to});
        }
    }
}

    이것이 바로 DijkstraComplete.java의 구조입니다. 수정 후 출력은 0, 3, 5, 9, 10, 13이 됩니다.

    13복잡도 및 특성 분석

    입력 크기

    정점 수 V와 간선 수 E, 두 개의 입력 크기로 표현합니다. 캠퍼스 그래프는 V=6, E=9였습니다.

    주요 연산

    뽑기(미확정 중 최솟값 선택)와 완화(dist 비교·갱신) 두 가지입니다. 뽑기는 정점마다 1번씩 총 V번, 완화는 무방향 그래프에서 간선마다 최대 2번씩 총 O(E)번 시도됩니다.

    시간 복잡도

    버전뽑기 1회완화 1회전체
    배열 버전 (Step4Relax)O(V) 훑기 × V회O(1)O(V² + E) ≈ O(V²)
    우선순위 큐 버전 (DijkstraComplete)O(log V) 꺼내기갱신 시 O(log V) 넣기O((V + E) log V)

    정점 10,000개, 간선 50,000개라면 배열 버전은 약 10⁸번, 큐 버전은 약 10⁶번 수준의 연산입니다. 간선이 듬성한(희소) 큰 그래프일수록 우선순위 큐 버전이 압도적으로 유리합니다. 반대로 정점이 수백 개뿐이라면 배열 버전도 충분히 빠르고 코드가 단순합니다.

    공간 복잡도

    인접 리스트 O(V + E), dist·prev·visited 배열 O(V), 우선순위 큐는 최악의 경우 간선마다 항목이 들어가 O(E)입니다. 전체 O(V + E)입니다.

    알고리즘 특성

    • 그리디 + 점화식의 결합: 확정은 그리디(10강), 갱신은 점화식(11강). 두 강의의 도구가 한 알고리즘 안에서 함께 일하는 대표 사례입니다.
    • 음수 가중치 불가: "가장 가까운 미확정 정점은 번복 불필요"라는 그리디 논리가 가중치 ≥ 0에 의존합니다. 음수 간선이 있으면 벨만-포드 등 다른 알고리즘이 필요합니다.
    • BFS는 다익스트라의 특수한 경우: 모든 가중치가 1이면 다익스트라의 확정 순서가 BFS의 방문 순서와 같아집니다. 우선순위 큐가 일반 큐처럼 동작하기 때문입니다.
    • 한 출발점 → 모든 정점: 다익스트라는 한 번 실행으로 출발점에서 모든 정점까지의 최단 거리를 구합니다(single-source). 특정 목적지 하나만 필요하면 그 정점이 확정되는 순간 멈춰도 됩니다.

    15실제 데이터 응용 예제

    문제 상황

    고속버스 회사의 앱에 "출발 도시에서 전국 주요 도시까지의 최소 소요 시간과 추천 경로"를 보여 주는 기능을 추가합니다. 도시 8개와 직행 노선 11개의 소요 시간(분) 데이터가 있습니다. 직행이 없는 도시는 환승으로 이어야 하고, 직행이 있어도 환승이 더 빠를 수 있습니다 — 정확히 다익스트라가 풀도록 설계된 문제입니다.

    데이터 모델과 알고리즘 적용 기준

    • 정점: 도시 8개 (서울, 인천, 대전, 전주, 광주, 대구, 울산, 부산)
    • 간선: 직행 노선 11개, 가중치 = 소요 시간(분), 양방향
    • 알고리즘: 가중치가 모두 양수 + 한 출발점에서 모든 도시 → 다익스트라 (우선순위 큐 버전)
    • 추가 요구: 경로 안내가 필요하므로 prev 배열로 경로 복원, 분 단위를 "n시간 m분"으로 표시
    Java ShortestPathApplication.java 
    import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;
import java.util.PriorityQueue;

public class ShortestPathApplication {

    static final int INF = Integer.MAX_VALUE;

    /** 간선 정보: 도착 도시 번호와 이동 시간(분) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    /** 다익스트라 결과: 최단 시간 배열 + 경로 복원용 직전 도시 배열 */
    static class Result {
        int[] dist;
        int[] prev;

        Result(int[] dist, int[] prev) {
            this.dist = dist;
            this.prev = prev;
        }
    }

    static void addRoad(List<List<Edge>> map, int u, int v, int minutes) {
        map.get(u).add(new Edge(v, minutes));
        map.get(v).add(new Edge(u, minutes));
    }

    /** 우선순위 큐 버전 다익스트라 (DijkstraComplete와 같은 구조) */
    static Result dijkstra(List<List<Edge>> map, int start) {
        int n = map.size();
        int[] dist = new int[n];
        int[] prev = new int[n];
        boolean[] visited = new boolean[n];
        Arrays.fill(dist, INF);
        Arrays.fill(prev, -1);
        dist[start] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(item -> item[0]));
        pq.add(new int[]{0, start});

        while (!pq.isEmpty()) {
            int[] item = pq.poll();
            int d = item[0];
            int u = item[1];
            if (visited[u]) {
                continue;
            }
            visited[u] = true;

            for (Edge e : map.get(u)) {
                int newDist = d + e.weight;
                if (newDist < dist[e.to]) {
                    dist[e.to] = newDist;
                    prev[e.to] = u;
                    pq.add(new int[]{newDist, e.to});
                }
            }
        }
        return new Result(dist, prev);
    }

    static String buildPath(int[] prev, String[] names, int end) {
        StringBuilder path = new StringBuilder(names[end]);
        int v = end;
        while (prev[v] != -1) {
            v = prev[v];
            path.insert(0, names[v] + " -> ");
        }
        return path.toString();
    }

    /** 분 단위 시간을 "n시간 m분" 형태로 바꾼다 */
    static String formatMinutes(int minutes) {
        if (minutes == INF) {
            return "도달 불가";
        }
        if (minutes < 60) {
            return minutes + "분";
        }
        if (minutes % 60 == 0) {
            return (minutes / 60) + "시간";
        }
        return (minutes / 60) + "시간 " + (minutes % 60) + "분";
    }

    public static void main(String[] args) {
        // 도시 8개와 고속버스 노선 11개 (이동 시간: 분)
        String[] cities = {"서울", "인천", "대전", "전주", "광주", "대구", "울산", "부산"};
        int n = cities.length;

        List<List<Edge>> map = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            map.add(new ArrayList<>());
        }
        addRoad(map, 0, 1, 40);   // 서울-인천
        addRoad(map, 0, 2, 65);   // 서울-대전
        addRoad(map, 1, 2, 95);   // 인천-대전
        addRoad(map, 2, 3, 50);   // 대전-전주
        addRoad(map, 2, 5, 70);   // 대전-대구
        addRoad(map, 3, 4, 45);   // 전주-광주
        addRoad(map, 3, 5, 85);   // 전주-대구
        addRoad(map, 4, 7, 140);  // 광주-부산
        addRoad(map, 5, 6, 50);   // 대구-울산
        addRoad(map, 5, 7, 65);   // 대구-부산
        addRoad(map, 6, 7, 30);   // 울산-부산

        int start = 0;   // 서울
        Result result = dijkstra(map, start);

        System.out.println("[고속버스 내비게이션] 출발: " + cities[start]);
        System.out.println();
        System.out.println("도착 | 소요 시간     | 추천 경로");
        System.out.println("-----+--------------+------------------------------");
        for (int v = 0; v < n; v++) {
            if (v == start) {
                continue;
            }
            System.out.printf("%s | %-12s | %s%n",
                    cities[v], formatMinutes(result.dist[v]),
                    buildPath(result.prev, cities, v));
        }

        System.out.println();
        System.out.println("가장 오래 걸리는 도시: " + cities[7] + " ("
                + formatMinutes(result.dist[7]) + ")");
        System.out.println("부산행은 광주 경유(65+50+45+140=300분)보다 대구 경유가 100분 빠르다.");
    }
}

    코드 해설과 복잡도 분석

    • dijkstra 메서드는 DijkstraComplete와 완전히 같은 구조입니다 — 정점이 "건물"에서 "도시"로, 가중치가 "도보 시간"에서 "버스 시간"으로 바뀌었을 뿐입니다. 알고리즘은 데이터의 의미와 무관하게 재사용됩니다.

    • 복잡도: V=8, E=11이므로 O((V+E) log V) ≈ 수십 번의 연산 — 실시간 응답에 충분합니다. 실제 전국 도로망(정점 수십만)에서도 우선순위 큐 버전이면 1초 안에 계산됩니다.

    16최종 프로그램 작성 문제

    문제 제목 — 동네 길찾기 "PathFinder"

    문제 배경

    여러분은 동네 커뮤니티 앱에 "도보 길찾기" 기능을 만들게 되었습니다. 동네에는 장소 7곳(집, 카페, 학교, 도서관, 공원, 병원, 체육관)이 있고, 장소 사이의 길마다 걷는 시간(분)이 조사되어 있습니다. 이용자가 목적지를 고르면 집에서 그곳까지의 최소 도보 시간과 경로를 보여 줘야 합니다. 한 가지 주의할 점: 새로 지은 체육관은 진입로가 공사 중이라 연결된 길이 하나도 없습니다. 이런 곳을 목적지로 고르면 프로그램이 엉뚱한 숫자를 보여 주는 대신 "도달 불가"라고 안내해야 합니다. 또 출발지와 목적지가 같은 경우(집 → 집)도 0분으로 자연스럽게 처리되어야 합니다.

    프로그램 목표

    배열 버전 다익스트라로 집에서 모든 장소까지의 최단 시간을 구하고, prev 배열로 경로를 복원하여 "시간 + 경로"를 출력하는 콘솔 프로그램을 완성합니다.

    필수 요구사항

    1. pickClosest(int[] dist, boolean[] visited) — 미확정 장소 중 거리가 가장 작은 번호를 반환한다. 없으면 -1.
    2. dijkstra(List<List<Edge>> map, int start) — 뽑기 → 확정 → 완화를 반복하고, 완화 시 prev를 기록한다.
    3. buildPath(int[] prev, String[] names, int end) — prev를 거슬러 올라가 "집 -> 카페 -> ..." 형태의 문자열을 만든다.
    4. 거리가 INF인 목적지는 경로 대신 "도달 불가"를 출력한다.
    5. 다익스트라 반복은 pickClosest가 -1을 반환하면 조기 종료한다.
    6. 핵심 알고리즘을 라이브러리(예: 외부 그래프 라이브러리)로 대체하지 않고 직접 구현한다.

    Java PathFinderSolution.java 
    import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

/**
 * 최종 프로그램 "동네 길찾기 PathFinder" — 정답 코드.
 * 배열 버전 다익스트라 + prev 경로 복원 + 도달 불가 처리.
 */
public class PathFinderSolution {

    static final int INF = Integer.MAX_VALUE;

    /** 간선 정보: 도착 장소 번호와 걷는 시간(분) */
    static class Edge {
        int to;
        int weight;

        Edge(int to, int weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    /** 다익스트라 결과: 최단 시간 배열 + 경로 복원용 직전 장소 배열 */
    static class Result {
        int[] dist;
        int[] prev;

        Result(int[] dist, int[] prev) {
            this.dist = dist;
            this.prev = prev;
        }
    }

    static void addPath(List<List<Edge>> map, int u, int v, int minutes) {
        map.get(u).add(new Edge(v, minutes));
        map.get(v).add(new Edge(u, minutes));
    }

    /** 미확정 장소 중 거리가 가장 작은 장소 번호를 반환한다. 없으면 -1 */
    static int pickClosest(int[] dist, boolean[] visited) {
        int minVertex = -1;
        int minDist = INF;
        for (int v = 0; v < dist.length; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                minVertex = v;
            }
        }
        return minVertex;
    }

    /** 배열 버전 다익스트라: start에서 모든 장소까지의 최단 시간과 직전 장소를 계산한다 */
    static Result dijkstra(List<List<Edge>> map, int start) {
        int n = map.size();
        int[] dist = new int[n];
        int[] prev = new int[n];
        boolean[] visited = new boolean[n];
        Arrays.fill(dist, INF);
        Arrays.fill(prev, -1);
        dist[start] = 0;

        for (int round = 0; round < n; round++) {
            int u = pickClosest(dist, visited);
            if (u == -1) {
                break;                        // 남은 장소는 모두 도달 불가
            }
            visited[u] = true;                // u까지의 최단 시간 확정

            for (Edge e : map.get(u)) {
                if (dist[u] + e.weight < dist[e.to]) {   // 완화 조건
                    dist[e.to] = dist[u] + e.weight;
                    prev[e.to] = u;                      // 경로 기록
                }
            }
        }
        return new Result(dist, prev);
    }

    /** prev 배열을 거슬러 올라가 "집 -> 카페 -> ..." 형태의 경로 문자열을 만든다 */
    static String buildPath(int[] prev, String[] names, int end) {
        StringBuilder path = new StringBuilder(names[end]);
        int v = end;
        while (prev[v] != -1) {
            v = prev[v];
            path.insert(0, names[v] + " -> ");
        }
        return path.toString();
    }

    public static void main(String[] args) {
        String[] names = {"집", "카페", "학교", "도서관", "공원", "병원", "체육관"};
        int n = names.length;

        List<List<Edge>> map = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            map.add(new ArrayList<>());
        }
        addPath(map, 0, 1, 4);   // 집-카페
        addPath(map, 0, 2, 10);  // 집-학교
        addPath(map, 1, 2, 3);   // 카페-학교
        addPath(map, 1, 3, 8);   // 카페-도서관
        addPath(map, 2, 3, 2);   // 학교-도서관
        addPath(map, 2, 4, 7);   // 학교-공원
        addPath(map, 3, 5, 5);   // 도서관-병원
        addPath(map, 4, 5, 1);   // 공원-병원
        // 체육관(6)은 진입로 공사 중이라 연결된 길이 아직 없다

        int start = 0;   // 집
        Result result = dijkstra(map, start);

        int[] targets = {5, 6, 0};   // 병원, 체육관, 집
        for (int end : targets) {
            if (result.dist[end] == INF) {
                System.out.println(names[start] + " -> " + names[end] + " : 도달 불가");
            } else {
                System.out.println(names[start] + " -> " + names[end] + " : "
                        + result.dist[end] + "분, 경로 "
                        + buildPath(result.prev, names, end));
            }
        }
    }

    • 시간: 뽑기 O(V) × V회 + 완화 O(E) = O(V² + E). V=7이므로 수십 번의 연산입니다.

    자주 발생하는 오류

    • pickClosest에서 !visited[v] 누락 → 출발점만 반복해서 뽑힘 (오류 1).
    • dist[u] + e.weight를 INF 검사 없이 아무 정점에나 계산 → 오버플로로 음수 거리. 이 구조에서는 pickClosest가 INF 정점을 반환하지 않으므로 안전하지만, 반복 구조를 바꿀 때는 반드시 다시 확인해야 합니다.
    • 완화 시 prev 기록 누락 → 거리는 정답, 경로는 엉망.
    • buildPath에서 무한 반복 → prev를 -1로 초기화하지 않았거나 출발점 prev를 덮어쓴 경우.

    pickClosest를 PriorityQueue로 바꾸면 DijkstraComplete와 같은 O((V+E) log V) 버전이 됩니다. 장소가 7개뿐인 이 문제에서는 체감 차이가 없지만, "무엇이 병목이고 언제 개선이 필요한가"를 판단하는 것 자체가 1강부터 연습해 온 복잡도 감각입니다. 경로를 저장하는 다른 방법으로, 정점마다 경로 문자열 전체를 들고 다닐 수도 있지만 메모리가 O(V²)로 늘어나므로 prev 배열 방식이 표준입니다.

    19오늘의 핵심 정리

    • 최단 경로 문제는 간선 수가 아니라 가중치의 합이 최소인 경로를 찾는 문제다. BFS(9강)는 무가중치(모든 가중치 동일)에서만 최단을 보장한다.
    • 거리 배열 dist는 "지금까지 알아낸 최선"이며, 출발점 0, 나머지 ∞(Integer.MAX_VALUE)로 시작한다. ∞에 덧셈을 하면 오버플로로 음수가 되므로 주의한다.
    • 완화(relaxation): dist[v] = min(dist[v], dist[u] + w) — 11강 점화식과 같은 모양의 갱신 규칙.
    • 다익스트라 = 그리디 확정 + 완화 반복. 미확정 중 dist가 가장 작은 정점은 그대로 확정해도 된다(가중치 ≥ 0일 때). 음수 가중치가 있으면 이 논리가 무너져 다익스트라를 쓸 수 없다(벨만-포드의 영역).
    • 뽑기를 배열 훑기로 하면 O(V²), 우선순위 큐(6·10강)로 하면 O((V+E) log V). 큐 버전은 꺼낼 때 확정하고, 이미 확정된 정점의 낡은 항목은 건너뛴다.
    • prev 배열에 "어디서 왔는지"를 기록하면 도착점에서 거꾸로 따라가 경로를 복원할 수 있다.
