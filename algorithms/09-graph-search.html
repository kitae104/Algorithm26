그래프와 DFS·BFS 탐색

Graphs, DFS, and BFS

그래프 중급 Java 17+

SNS 친구 관계, 지하철 노선도, 웹 페이지의 링크 — 세상의 많은 데이터는 "무엇과 무엇이 연결되어 있는가"의 형태입니다. 이번 강의에서는 이런 연결 데이터를 표현하는 그래프를 인접 리스트로 만들고, 6강의 스택·큐와 7강의 재귀를 다시 꺼내 DFS(깊이 우선 탐색)와 BFS(너비 우선 탐색)로 그래프 전체를 빠짐없이, 그리고 무한 반복 없이 탐험하는 방법을 배웁니다.

이 강의의 목차

    01강의 소개

    지금까지 우리가 다룬 자료구조에는 모두 "정해진 길"이 있었습니다. 배열은 앞에서 뒤로 한 줄, 트리는 루트에서 리프로 갈라지는 한 방향이었습니다. 그런데 친구 관계를 생각해 보세요. 민준의 친구가 서연이고, 서연의 친구가 하은인데, 하은이 다시 민준의 다른 친구 지호와 친구라면? 연결이 빙 돌아 되돌아오는 순환이 생깁니다. 이런 자유로운 연결을 표현하는 자료구조가 그래프(graph)입니다.

    그래프는 길이 정해져 있지 않기 때문에, 모든 정점을 빠짐없이 살펴보려면 탐색 전략이 필요합니다. 오늘은 두 가지 대표 전략을 배웁니다. 한 길을 끝까지 파고드는 DFS(깊이 우선 탐색)는 7강의 재귀(또는 6강의 스택)로, 가까운 곳부터 물결처럼 퍼지는 BFS(너비 우선 탐색)는 6강의 큐로 구현합니다. 그리고 같은 곳을 두 번 밟아 무한 반복에 빠지지 않도록 지켜 주는 방문 배열이 오늘의 숨은 주인공입니다. 마지막에는 SNS 친구 네트워크를 분석하는 프로그램을 직접 완성합니다.

    02학습 목표

    이 강의를 마치면 다음을 할 수 있습니다.

    • 학생은 연결 관계 문제(친구, 노선, 링크)를 정점과 간선으로 이루어진 그래프로 모델링할 수 있다.
    • 학생은 간선 목록으로부터 인접 리스트(List<List<Integer>>)를 만들고, 인접 행렬과의 장단점을 비교할 수 있다.
    • 학생은 방문 배열이 없을 때 순환 그래프에서 무슨 일이 일어나는지 설명하고, 올바른 방문 표시 시점을 코드로 구현할 수 있다.
    • 학생은 재귀와 스택 두 가지 방법으로 DFS를 구현하고 방문 순서를 손으로 추적할 수 있다.
    • 학생은 큐를 이용한 BFS를 구현하고, BFS가 "간선 수 기준 최단 거리"를 찾는 이유를 설명할 수 있다.
    • 학생은 DFS를 반복 시작하여 그래프의 연결 요소(끼리끼리 무리) 개수를 셀 수 있다.

    04실제 문제 상황

    여러분은 소규모 SNS 서비스의 개발자입니다. 어느 날 기획팀이 세 가지 기능을 요청했습니다. 첫째, 회원 A가 친구의 친구를 타고 도달할 수 있는 사람을 모두 찾아 "알 수도 있는 사람"으로 추천할 것. 둘째, A와 B가 몇 다리 건너 아는 사이인지(최소 몇 단계 만에 연결되는지) 보여줄 것. 셋째, 전체 회원이 몇 개의 친구 그룹(서로 아예 연결이 없는 무리)으로 나뉘어 있는지 통계를 낼 것. 친구 관계는 "민준-서연", "서연-하은"처럼 쌍의 목록으로만 저장되어 있습니다. 쌍의 목록을 뒤지는 것만으로는 "친구의 친구의 친구"를 따라가기가 너무 번거롭습니다. 연결 관계를 다루기 좋은 구조로 바꾸고, 그 위를 체계적으로 탐험하는 방법이 필요합니다.

    오늘의 핵심 질문

    연결이 얽혀 있고 순환까지 있는 데이터 위를, 어떻게 하면 빠짐없이 · 딱 한 번씩만 돌아다닐 수 있을까?

    05사람이 직접 해결해 보기

    코드를 쓰기 전에 작은 데이터로 손으로 풀어 봅니다. 회원 7명(0~6번)과 친구 관계 6쌍이 있습니다: (0,1), (0,2), (1,3), (2,4), (3,5), (4,5). 6번 회원은 아직 친구가 없습니다.

    먼저, 그림으로 그리기

    STEP 1

    종이에 동그라미 7개(0~6)를 그리고, 쌍마다 선으로 잇습니다. 0 아래에 1과 2가, 1 아래에 3이, 2 아래에 4가, 그리고 3과 4가 5에서 다시 만나는 모양이 됩니다. 6은 어디에도 이어지지 않은 외딴 점입니다.

    질문: 이 그림은 8강의 트리와 무엇이 다른가요?

    두 가지가 다릅니다. 첫째, 0 → 1 → 3 → 5 → 4 → 2 → 0으로 빙 돌아 되돌아오는 순환이 있습니다 (트리에는 순환이 없습니다). 둘째, 5로 가는 길이 3을 거치는 길과 4를 거치는 길, 두 갈래입니다 (트리에서는 어떤 노드로 가는 길이 항상 하나뿐입니다). 게다가 6처럼 아예 떨어져 있는 정점도 있습니다.

    방법 A — 한 우물 파기 (DFS의 손 풀이)

    STEP 2

    0번에서 출발해, 갈 수 있으면 무조건 더 깊이 들어가 봅니다. 방문한 번호에는 형광펜을 칠합니다(방문 표시). 0 → 이웃 중 번호가 작은 1로 → 1의 미방문 이웃 3으로 → 3의 미방문 이웃 5로 → 5의 미방문 이웃 4로 → 4의 미방문 이웃 2로. 2의 이웃 0과 4는 이미 형광펜이 칠해져 있으니 더 갈 곳이 없습니다.

    질문: 2에서 막혔습니다. 이제 어떻게 해야 하나요?

    왔던 길을 거슬러 되돌아갑니다(backtrack). 4로, 5로, 3으로, 1로, 0으로 돌아가며 "아직 안 가 본 이웃이 있나?"를 확인합니다. 0의 이웃 2도 이미 방문했으므로 탐색 종료. 방문 순서는 0 → 1 → 3 → 5 → 4 → 2입니다. 이 "되돌아갈 곳 기억하기"를 프로그램에서는 7강의 재귀(호출 스택)가 자동으로 해 줍니다.

    STEP 3

    이번엔 형광펜(방문 표시) 없이 같은 규칙으로 가 봅시다. 0 → 1 → (1의 이웃) 0 → (0의 이웃) 1 → …

    질문: 무슨 일이 일어났나요?

    0과 1 사이를 영원히 왕복합니다. 간선은 양방향이므로 "왔던 곳"도 이웃이기 때문입니다. 트리 순회(8강)에서는 부모→자식 한 방향이라 이런 일이 없었지만, 그래프에서는 방문 표시가 무한 반복을 막는 유일한 안전장치입니다.

    방법 B — 물결처럼 퍼지기 (BFS의 손 풀이)

    STEP 4

    이번에는 0번에서 가까운 순서대로 방문합니다. 먼저 0(0다리). 다음은 0의 직접 이웃 1, 2(1다리). 다음은 그들의 이웃 3, 4(2다리). 마지막으로 5(3다리). "다음에 갈 곳"을 잊지 않도록 대기 명단(줄 세우기)에 적어 두고, 명단 앞에서부터 처리합니다.

    질문: 5는 3에서도, 4에서도 갈 수 있습니다. 명단에 두 번 적어야 하나요?

    안 됩니다. 명단에 적는 순간 형광펜을 칠해서, 이미 명단에 오른 사람은 다시 적지 않아야 합니다. 그래야 5가 한 번만 처리됩니다. 방문 순서는 0 → 1 → 2 → 3 → 4 → 5. "먼저 발견된 곳부터 처리"하는 이 대기 명단이 바로 6강의 큐(FIFO)입니다. 그리고 이렇게 퍼지면 각 정점에 가장 적은 다리 수로 처음 도달하게 됩니다 — 이것이 BFS가 최단 거리(간선 수 기준)를 찾는 이유입니다.

    STEP 5

    두 방법을 비교합니다. 방문 순서는 다르지만(0,1,3,5,4,2 vs 0,1,2,3,4,5) 둘 다 연결된 6개 정점을 정확히 한 번씩 방문했고, 외딴 6번에는 도달하지 못했습니다.

    질문: "도달하지 못한 6번"은 어떻게 발견할 수 있을까요?

    탐색이 끝난 뒤 형광펜이 안 칠해진 번호를 찾으면 됩니다. 그런 정점에서 탐색을 새로 시작하면 또 하나의 무리를 발견하는 것이고, 새로 시작한 횟수가 곧 연결 요소(그룹)의 개수입니다. 이 그래프는 {0~5}와 {6}, 2개의 무리로 되어 있습니다.

    06핵심 개념

    그래프 = 정점 + 간선

    그래프는 정점(vertex, 노드)의 집합과 정점 사이를 잇는 간선(edge)의 집합입니다. 친구 관계처럼 연결에 방향이 없으면 무방향 그래프(A-B이면 B-A이기도 함), SNS 팔로우처럼 한쪽으로만 향하면 방향 그래프(A→B라고 B→A는 아님)입니다. 이번 강의는 무방향 그래프가 중심이고, 방향 그래프는 실습에서 다룹니다.

    실생활 데이터정점간선방향
    SNS 친구 관계회원친구 사이무방향
    SNS 팔로우회원팔로우방향
    지하철 노선도역이웃 역 구간무방향

    트리와 무엇이 다른가

    • 트리는 순환이 없는 특별한 그래프입니다. 그래프에는 순환이 있을 수 있습니다.
    • 트리에는 루트와 부모·자식 방향이 있지만, 그래프에는 정해진 출발점이 없습니다 — 탐색할 때 우리가 정합니다.
    • 트리에서 두 노드 사이 경로는 하나뿐이지만, 그래프에는 여러 경로가 있을 수 있습니다(0에서 5로 가는 길이 두 갈래였듯).
    • 연결되지 않은 정점(고립된 6번)이 있을 수도 있습니다.

    그래프를 코드로 담는 두 가지 방법

    간선을 "쌍의 목록"으로 받은 뒤, 탐색하기 좋은 구조로 바꿉니다. 인접 리스트는 정점마다 이웃 목록을 저장하고(List<List<Integer>>), 인접 행렬은 matrix[i][j] = 1로 연결 여부를 2차원 배열에 저장합니다.

    비교 항목인접 리스트인접 행렬
    메모리O(V + E) — 실제 간선만큼만O(V²) — 연결이 없어도 칸 차지
    "v의 모든 이웃" 순회이웃 수만큼만 — 빠름V칸 전부 확인
    "u-v 연결?" 한 번 확인이웃 목록 뒤져야 함O(1) — matrix[u][v]
    어울리는 그래프간선이 적은 희소 그래프 (SNS, 노선도)정점이 적고 촘촘한 그래프

    탐색(DFS·BFS)은 "이웃 순회"가 핵심 연산이므로, 이번 강의는 인접 리스트를 사용합니다. (V = 정점 수, E = 간선 수)

    방문 배열 — 무한 반복을 막는 안전장치

    boolean[] visited는 정점 번호를 인덱스로 쓰는 배열입니다. 손 풀이의 형광펜이 곧 visited[v] = true입니다. 무방향 간선에서는 "방금 왔던 곳"도 이웃이고, 순환이 있으면 돌아온 길로 또 나아가므로, 방문 표시 없이는 DFS는 무한 재귀(StackOverflowError), BFS는 큐가 영원히 비지 않는 상태가 됩니다. 방문 표시의 시점도 중요합니다 — BFS는 큐에서 꺼낼 때가 아니라 큐에 넣는 순간 표시해야 같은 정점이 큐에 중복으로 들어가지 않습니다(오류 찾기 섹션에서 확인).

    DFS vs BFS

    비교 항목DFS (깊이 우선)BFS (너비 우선)
    전략한 길을 끝까지, 막히면 되돌아오기가까운 정점부터 물결처럼
    보조 도구재귀(호출 스택) 또는 스택 — LIFO큐 — FIFO
    8강의 짝전위 순회의 일반화레벨 순회의 일반화
    잘하는 일경로 존재 확인, 연결 요소, 백트래킹류 문제간선 수 기준 최단 거리, 가까운 것부터 찾기
    주의점깊은 그래프에서 재귀 깊이(스택 오버플로)넓은 그래프에서 큐 메모리

    연결 요소 (connected component)

    한 번의 DFS/BFS는 출발점과 연결된 무리 하나만 방문합니다. 전체 정점을 훑으며 미방문 정점을 만날 때마다 탐색을 새로 시작하면, 시작한 횟수가 곧 그래프의 무리(연결 요소) 개수입니다. "전체 회원이 몇 개의 친구 그룹으로 나뉘는가"가 정확히 이 문제입니다.

    07단계별 동작 과정

    같은 그래프(손 풀이와 동일한 7개 정점)를 1부: 스택 DFS → 2부: 큐 BFS 순서로 탐색하는 과정입니다. 다음 단계 ▶ 버튼으로 한 단계씩 진행하세요. 파란색 + "지금 처리 중"은 방금 스택/큐에서 꺼내 처리하는 정점, 노란색 + "대기 중"은 스택/큐 안에서 차례를 기다리는 정점, 초록색 + "n번째 방문"은 방문이 끝난 정점입니다. 그래프 아래에 스택/큐의 실제 내용이 함께 표시됩니다.

    마지막 비교 단계에서 볼 수 있듯, 같은 그래프·같은 출발점이라도 보조 도구가 스택(LIFO)이냐 큐(FIFO)냐에 따라 DFS는 0 → 1 → 3 → 5 → 4 → 2, BFS는 0 → 1 → 2 → 3 → 4 → 5로 방문 순서가 달라집니다. 간선이 없는 6번은 두 방법 모두 도달하지 못합니다.

    알고리즘 DFS(그래프, v)
    visited[v] ← 참              // 1) 도착 즉시 방문 표시 (무한 반복 방지)
    v를 방문 순서에 기록한다        // 2) 처리
    v의 각 이웃 next에 대해 반복:
        만약 visited[next]가 거짓이면:
            DFS(그래프, next)     // 3) 더 깊이 — 되돌아오기는 호출 스택이 담당
    Pseudo BFS — 큐 버전 
    알고리즘 BFS(그래프, 출발점 start)
    visited[start] ← 참           // 큐에 "넣는 순간" 방문 표시!
    큐에 start를 넣는다
    큐가 비어 있지 않은 동안 반복:
        v ← 큐에서 꺼낸다 (front)
        v를 방문 순서에 기록한다
        v의 각 이웃 next에 대해 반복:
            만약 visited[next]가 거짓이면:
                visited[next] ← 참    // 넣을 때 표시해야 중복 삽입이 없다
                큐에 next를 넣는다

    두 의사코드의 뼈대는 같습니다 — "꺼내서 처리하고, 미방문 이웃을 보관함에 넣는다". 보관함이 호출 스택/스택(나중 것 먼저)이면 DFS, 큐(먼저 것 먼저)이면 BFS가 됩니다.

    "한 걸음"을 재귀 호출로 바꿉니다. dfs(v)는 (1) 방문 표시, (2) 방문 순서 기록, (3) 미방문 이웃마다 dfs(이웃) 호출 — 딱 세 줄 구조입니다. 호출이 반환되는 것이 곧 "되돌아가기(백트래킹)"입니다.

    Java Step4RecursiveDfs.java 
    import java.util.ArrayList;
import java.util.List;

public class Step4RecursiveDfs {

    static List<List<Integer>> adjacency = new ArrayList<>();
    static boolean[] visited;
    static List<Integer> visitOrder = new ArrayList<>();

    /** 재귀 DFS: 정점 v를 방문하고, 미방문 이웃마다 자기 자신을 다시 호출한다 */
    static void dfs(int v) {
        visited[v] = true;       // 1) 방문 표시 (순환 그래프에서 무한 재귀를 막는다)
        visitOrder.add(v);       // 2) 방문 순서 기록
        System.out.println("dfs(" + v + ") 호출 — " + v + "번 방문");

        for (int neighbor : adjacency.get(v)) {
            if (!visited[neighbor]) {   // 3) 미방문 이웃으로만 더 깊이 들어간다
                dfs(neighbor);
            }
        }
    }

    public static void main(String[] args) {
        int vertexCount = 7;
        int[][] edges = { {0, 1}, {0, 2}, {1, 3}, {2, 4}, {3, 5}, {4, 5} };
        for (int v = 0; v < vertexCount; v++) {
            adjacency.add(new ArrayList<>());
        }
        for (int[] edge : edges) {
            adjacency.get(edge[0]).add(edge[1]);
            adjacency.get(edge[1]).add(edge[0]);
        }
        visited = new boolean[vertexCount];

        dfs(0);

        System.out.println();
        StringBuilder order = new StringBuilder();
        for (int i = 0; i < visitOrder.size(); i++) {
            if (i > 0) order.append(" → ");
            order.append(visitOrder.get(i));
        }
        System.out.println("DFS 방문 순서: " + order);
        System.out.println("방문한 정점 수: " + visitOrder.size() + " / 전체 " + vertexCount

    }

    10완성 Java 코드

    지금까지의 조각을 모아 그래프 탐색 도구 세트를 완성합니다. 재귀 DFS, 재귀 대신 6강의 스택으로 "되돌아갈 곳"을 직접 관리하는 스택 DFS, 큐를 쓰는 BFS, 그리고 미방문 정점마다 DFS를 새로 시작해 연결 요소 개수를 세는 메서드까지 네 가지입니다.

    Java GraphSearchComplete.java 
    import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

public class GraphSearchComplete {

    /** 간선 목록으로 무방향 그래프의 인접 리스트를 만든다 */
    static List<List<Integer>> buildAdjacency(int vertexCount, int[][] edges) {
        List<List<Integer>> adjacency = new ArrayList<>();
        for (int v = 0; v < vertexCount; v++) {
            adjacency.add(new ArrayList<>());
        }
        for (int[] edge : edges) {
            adjacency.get(edge[0]).add(edge[1]);
            adjacency.get(edge[1]).add(edge[0]);
        }
        return adjacency;
    }

    /** 방법 1: 재귀 DFS — 미방문 이웃을 만나면 즉시 더 깊이 들어간다 */
    static void dfsRecursive(List<List<Integer>> adjacency, int v,
                             boolean[] visited, List<Integer> order) {
        visited[v] = true;
        order.add(v);
        for (int neighbor : adjacency.get(v)) {
            if (!visited[neighbor]) {
                dfsRecursive(adjacency, neighbor, visited, order);
            }
        }
    }

    /** 방법 2: 스택 DFS — 재귀 대신 스택으로 "되돌아갈 곳"을 직접 관리한다 */
    static List<Integer> dfsWithStack(List<List<Integer>> adjacency, int start) {
        boolean[] visited = new boolean[adjacency.size()];
        List<Integer> order = new ArrayList<>();
        Deque<Integer> stack = new ArrayDeque<>();

        stack.push(start);
        while (!stack.isEmpty()) {
            int v = stack.pop();
            if (visited[v]) {
                continue;   // 스택에 중복으로 들어간 정점은 건너뛴다
            }
            visited[v] = true;
            order.add(v);

            // 재귀 DFS와 같은 방문 순서가 되도록 이웃을 역순으로 push 한다
            List<Integer> neighbors = adjacency.get(v);
            for (int i = neighbors.size() - 1; i >= 0; i--) {
                if (!visited[neighbors.get(i)]) {
                    stack.push(neighbors.get(i));
                }
            }
        }
        return order;
    }

    /** 방법 3: 큐 BFS — 가까운 정점부터 물결처럼 넓게 퍼져 나간다 */
    static List<Integer> bfs(List<List<Integer>> adjacency, int start) {
        boolean[] visited = new boolean[adjacency.size()];
        List<Integer> order = new ArrayList<>();
        Deque<Integer> queue = new ArrayDeque<>();

        visited[start] = true;   // 큐에 "넣을 때" 방문 표시한다 (중복 삽입 방지)
        queue.offer(start);
        while (!queue.isEmpty()) {
            int v = queue.poll();
            order.add(v);
            for (int neighbor : adjacency.get(v)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                }
            }
        }
        return order;
    }

    /** 연결 요소 개수: 미방문 정점을 만날 때마다 DFS를 새로 시작한다 */
    static int countComponents(List<List<Integer>> adjacency) {
        boolean[] visited = new boolean[adjacency.size()];
        int count = 0;
        for (int v = 0; v < adjacency.size(); v++) {
            if (!visited[v]) {
                count++;   // 새 무리를 발견했다
                dfsRecursive(adjacency, v, visited, new ArrayList<>());
            }
        }
        return count;
    }

    public static void main(String[] args) {
        int vertexCount = 7;
        int[][] edges = { {0, 1}, {0, 2}, {1, 3}, {2, 4}, {3, 5}, {4, 5} };
        List<List<Integer>> adjacency = buildAdjacency(vertexCount, edges);

        boolean[] visited = new boolean[vertexCount];
        List<Integer> recursiveOrder = new ArrayList<>();
        dfsRecursive(adjacency, 0, visited, recursiveOrder);

        System.out.println("재귀 DFS 방문 순서: " + recursiveOrder);
        System.out.println("스택 DFS 방문 순서: " + dfsWithStack(adjacency, 0));
        System.out.println("큐 BFS 방문 순서  : " + bfs(adjacency, 0));
        System.out.println("연결 요소 개수    : " + countComponents(adjacency)
                + "개 (0~5번 무리, 홀로 떨어진 6번)");
    }
}

스택 DFS 방문 순서: [0, 1, 3, 5, 4, 2]

    첫째, 꺼낸 정점이 이미 방문됐으면 continue로 건너뜁니다 — 같은 정점이 방문 전에 스택에 두 번 들어갈 수 있기 때문입니다(이 그래프에서는 2가 그렇습니다). 둘째, 이웃을 역순으로 push 합니다 — 스택은 나중에 넣은 것을 먼저 꺼내므로, 역순으로 넣어야 재귀 DFS처럼 앞쪽 이웃부터 방문합니다. 출력에서 재귀 DFS와 스택 DFS의 방문 순서가 완전히 같음을 확인하세요.

    BFS가 정말 시각화 2부와 똑같이 동작하는지, 매 단계의 큐 내용과 방문 배열을 출력해 확인합니다. 방문 배열은 0~6번 순서의 O/X 문자열로 표시합니다.

    Java BfsTrace.java 
    import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

public class BfsTrace {

    /** 방문 배열을 "OXXXXXX" 형태의 문자열로 만든다 (O = 방문, X = 미방문) */
    static String visitedText(boolean[] visited) {
        StringBuilder sb = new StringBuilder();
        for (boolean v : visited) {
            sb.append(v ? "O" : "X");
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        int vertexCount = 7;
        int[][] edges = { {0, 1}, {0, 2}, {1, 3}, {2, 4}, {3, 5}, {4, 5} };

        List<List<Integer>> adjacency = new ArrayList<>();
        for (int v = 0; v < vertexCount; v++) {
            adjacency.add(new ArrayList<>());
        }
        for (int[] edge : edges) {
            adjacency.get(edge[0]).add(edge[1]);
            adjacency.get(edge[1]).add(edge[0]);
        }

        int start = 0;
        boolean[] visited = new boolean[vertexCount];
        Deque<Integer> queue = new ArrayDeque<>();
        List<Integer> order = new ArrayList<>();

        visited[start] = true;
        queue.offer(start);
        System.out.println("[BFS 실행 추적] 시작 정점: " + start + " (방문 배열은 0~6번 순서)");
        System.out.println("준비   | 큐에 0 넣고 방문 표시      | 큐 " + queue
                + " | 방문 " + visitedText(visited));

        int stepNo = 0;
        while (!queue.isEmpty()) {
            int v = queue.poll();
            order.add(v);

            List<Integer> added = new ArrayList<>();
            for (int neighbor : adjacency.get(v)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;   // 큐에 넣는 순간 방문 표시!
                    queue.offer(neighbor);
                    added.add(neighbor);
                }
            }
            stepNo++;
            System.out.printf("%d단계  | 꺼냄 %d, 새로 넣음 %-7s | 큐 %-6s | 방문 %s%n",
                    stepNo, v, added, queue, visitedText(visited));
        }

        System.out.println();
        System.out.println("큐가 비어 탐색 종료. BFS 방문 순서: " + order);
        System.out.println("시작 정점에서 가까운 순서(0다리 → 1다리 → 2다리 → 3다리)로 방문했습니다.");
    }
}

    13복잡도 및 특성 분석

    입력 크기

    그래프의 크기는 숫자 두 개로 표현합니다 — 정점 수 V와 간선 수 E. 오늘의 예제는 V=7, E=6이었습니다.

    주요 연산

    핵심 연산은 정점 방문(방문 표시 + 기록)과 간선 확인(이웃 순회)입니다. 방문 배열 덕분에 각 정점은 정확히 한 번 방문되고, 각 간선은 양 끝에서 한 번씩, 최대 두 번 확인됩니다.

    시간 복잡도

    알고리즘인접 리스트인접 행렬이유
    DFS (재귀·스택)O(V + E)O(V²)정점 V번 방문 + 간선 2E번 확인 / 행렬은 정점마다 V칸 확인
    BFS (큐)O(V + E)O(V²)큐에 V번 넣고 빼고 + 간선 2E번 확인
    연결 요소 세기O(V + E)O(V²)전체 정점·간선을 통틀어 각 한 번씩 처리

    연결 요소 세기가 "DFS를 여러 번 시작"하는데도 O(V + E)인 이유: 방문 배열을 공유하므로, 몇 번을 새로 시작하든 전체적으로 각 정점·간선은 한 번씩만 처리되기 때문입니다.

    공간 복잡도

    • 인접 리스트 자체: O(V + E), 인접 행렬은 O(V²).
    • 방문 배열: O(V).
    • DFS의 재귀 깊이(호출 스택) 또는 명시적 스택: 최악 O(V) — 정점이 한 줄로 이어진 그래프에서 가장 깊어집니다.
    • BFS의 큐: 최악 O(V) — 한 정점에 이웃이 몰려 있는 그래프에서 가장 넓어집니다.

    알고리즘 특성

    • 방문 집합은 같다: DFS든 BFS든 출발점과 연결된 정점 전체를 정확히 한 번씩 방문합니다. 순서만 다릅니다.
    • BFS의 보증: 모든 간선의 비용이 같을 때, BFS가 각 정점에 처음 도달한 경로는 간선 수 기준 최단 경로입니다. 간선마다 비용이 다르면 BFS로는 부족합니다 — 12강의 다익스트라가 이 문제를 풉니다.
    • DFS의 재귀 깊이 한계: 정점이 수십만 개인 깊은 그래프에서는 재귀 DFS가 StackOverflowError를 낼 수 있어, 실무·코딩 테스트에서는 스택 DFS로 바꾸기도 합니다. 두 버전을 모두 익혀 두세요.

    15실제 데이터 응용 예제

    문제 상황

    지하철 앱을 만든다고 합시다. 승객이 가장 많이 묻는 질문은 "여기서 저 역까지 몇 정거장이야? 어떤 길로 가?"입니다. 역과 역 사이 구간(간선)의 소요 시간이 모두 비슷하다고 가정하면, 이것은 간선 수 기준 최단 거리 문제 — 정확히 BFS가 잘하는 일입니다. BFS를 조금만 확장해 거리와 경로까지 구해 봅니다.

    static int[][] bfsDistanceAndPrevious(List<List<Integer>> adjacency, int start) {
        int stationCount = adjacency.size();
        int[] distance = new int[stationCount];
        int[] previous = new int[stationCount];
        Arrays.fill(distance, -1);   // -1 = 아직 도달하지 못함 (방문 배열 역할도 겸한다)
        Arrays.fill(previous, -1);

        Deque<Integer> queue = new ArrayDeque<>();
        distance[start] = 0;
        queue.offer(start);

        while (!queue.isEmpty()) {
            int v = queue.poll();
            for (int neighbor : adjacency.get(v)) {
                if (distance[neighbor] == -1) {
                    distance[neighbor] = distance[v] + 1;   // 한 정거장 더 간 거리
                    previous[neighbor] = v;                 // 어디서 왔는지 기록
                    queue.offer(neighbor);
                }
            }
        }
        return new int[][] { distance, previous };
    }

    /** previous 배열을 목적지에서 출발지까지 거슬러 올라가 경로를 복원한다 */
    static List<Integer> buildPath(int[] previous, int goal) {
        List<Integer> path = new ArrayList<>();
        for (int v = goal; v != -1; v = previous[v]) {
            path.add(0, v);   // 앞쪽에 끼워 넣어 출발지 → 목적지 순서로 만든다
        }
        return path;
    }

        // 지하철 노선 소그래프: 역 이름 배열 + 역 사이 연결(간선)
        String[] stations = {"시청", "강변", "공원", "대학", "터미널", "시장", "병원"};
        int[][] links = { {0, 1}, {0, 2}, {1, 3}, {2, 3}, {3, 4}, {2, 5}, {5, 6}, {4, 6} };

    Java FriendNetworkSolution.java 
    import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Deque;
import java.util.List;

public class FriendNetworkSolution {

    /** 요구 1: 친구 쌍 목록으로 인접 리스트를 만든다 */
    static List<List<Integer>> buildAdjacency(int userCount, int[][] friendships) {
        List<List<Integer>> adjacency = new ArrayList<>();
        for (int v = 0; v < userCount; v++) {
            adjacency.add(new ArrayList<>());
        }
        for (int[] pair : friendships) {
            adjacency.get(pair[0]).add(pair[1]);   // 친구 관계는 서로 대칭이므로
            adjacency.get(pair[1]).add(pair[0]);   // 양쪽 리스트에 모두 추가한다
        }
        return adjacency;
    }

    /** 요구 2: v에서 DFS로 도달 가능한 사용자를 visitOrder에 방문 순서대로 담는다 */
    static void dfs(List<List<Integer>> adjacency, int v,
                    boolean[] visited, List<Integer> visitOrder) {
        visited[v] = true;       // 방문 표시가 없으면 친구 관계의 순환에서 무한 재귀!
        visitOrder.add(v);
        for (int neighbor : adjacency.get(v)) {
            if (!visited[neighbor]) {
                dfs(adjacency, neighbor, visited, visitOrder);
            }
        }
    }

    /** 요구 3: BFS로 start에서 각 사용자까지의 최소 다리 수를 구한다 (연결 없으면 -1) */
    static int[] bfsDistances(List<List<Integer>> adjacency, int start) {
        int[] distance = new int[adjacency.size()];
        Arrays.fill(distance, -1);
        Deque<Integer> queue = new ArrayDeque<>();

        distance[start] = 0;     // 거리 기록 = 방문 표시 (큐에 넣을 때 기록한다)
        queue.offer(start);
        while (!queue.isEmpty()) {
            int v = queue.poll();
            for (int neighbor : adjacency.get(v)) {
                if (distance[neighbor] == -1) {
                    distance[neighbor] = distance[v] + 1;
                    queue.offer(neighbor);
                }
            }
        }
        return distance;
    }

    /** 요구 4: 전체 친구 그룹(연결 요소) 수를 센다 */
    static int countGroups(List<List<Integer>> adjacency) {
        boolean[] visited = new boolean[adjacency.size()];
        int groupCount = 0;
        for (int v = 0; v < adjacency.size(); v++) {
            if (!visited[v]) {
                groupCount++;    // 새 그룹 발견
                dfs(adjacency, v, visited, new ArrayList<>());
            }
        }
        return groupCount;
    }

    public static void main(String[] args) {
        // SNS 친구 네트워크: 사용자 8명과 친구 관계(쌍)
        String[] users = {"민준", "서연", "지호", "하은", "도윤", "예린", "시우", "지아"};
        int[][] friendships = { {0, 1}, {0, 2}, {1, 3}, {2, 3}, {4, 5}, {5, 6} };

        List<List<Integer>> adjacency = buildAdjacency(users.length, friendships);

        System.out.println("[1] 인접 리스트");
        for (int v = 0; v < users.length; v++) {
            System.out.println("  " + v + " " + users[v] + ": " + adjacency.get(v));
        }

        System.out.println();
        System.out.println("[2] " + users[0] + "에서 DFS로 도달 가능한 친구망");
        boolean[] visited = new boolean[users.length];
        List<Integer> reachable = new ArrayList<>();
        dfs(adjacency, 0, visited, reachable);
        StringBuilder names = new StringBuilder();
        for (int i = 0; i < reachable.size(); i++) {
            if (i > 0) {
                names.append(" → ");
            }
            names.append(users[reachable.get(i)]);
        }
        System.out.println("  방문 순서: " + names + " (" + reachable.size() + "명)");

        System.out.println();
        System.out.println("[3] " + users[0] + " 기준 \"몇 다리 건너 아는 사이\" (BFS 최소 거리)");
        int[] distance = bfsDistances(adjacency, 0);
        for (int v = 1; v < users.length; v++) {
            String text = (distance[v] == -1) ? "연결 없음" : distance[v] + "다리";
            System.out.println("  " + users[v] + ": " + text);
        }

        System.out.println();
        System.out.println("[4] 전체 친구 그룹 수: " + countGroups(adjacency) + "개");
    }
}

    구현 순서와 핵심 알고리즘 적용 부분

    1. buildAdjacency — 무방향이므로 양쪽 추가가 전부입니다. 한쪽만 추가하면 [2]의 친구망과 [3]의 거리가 모두 틀어집니다.
    2. dfs — 구현 4단계의 세 줄 구조 그대로입니다. 방문 순서가 민준 → 서연 → 하은 → 지호인 이유: 서연(1)의 이웃 [0, 3]에서 미방문인 3(하은)으로 먼저 내려가고, 하은의 이웃 [1, 2]에서 2(지호)로 이어지기 때문입니다. 지호는 민준의 직접 친구인데도 DFS에서는 나중에 방문됩니다 — 깊이 우선의 특징입니다.
    3. bfsDistances — distance[neighbor] == -1 확인이 방문 확인이고, distance[v] + 1 기록이 "물결이 한 칸 더 퍼짐"입니다. 같은 사람은 처음 발견됐을 때의 거리(=최소)로 고정됩니다.
    4. countGroups — 이미 만든 dfs를 재사용합니다. 결과를 쓰지 않으므로 방문 순서 리스트는 새로 만들어 버립니다. {민준, 서연, 지호, 하은}, {도윤, 예린, 시우}, {지아} — 3개 그룹.

    19오늘의 핵심 정리

    • 그래프는 정점과 간선으로 연결 관계를 표현한다. 트리와 달리 순환·여러 경로·고립 정점이 있을 수 있다.
    • 간선 쌍 목록은 인접 리스트(List<List<Integer>>)로 바꿔 다룬다. 무방향 간선은 양쪽에 추가. 희소 그래프에서 인접 행렬(O(V²))보다 메모리 효율이 좋다.
    • 방문 배열은 그래프 탐색의 생존 장치다 — 없으면 순환에서 무한 반복. DFS는 도착 즉시, BFS는 큐에 넣는 순간 표시한다.
    • DFS(재귀 또는 스택, LIFO)는 한 길을 끝까지 파고들고, BFS(큐, FIFO)는 가까운 곳부터 물결처럼 퍼진다. 같은 그래프에서 방문 집합은 같고 순서만 다르다.
    • BFS의 방문 순서 = 거리 순서이므로, 가중치 없는 그래프의 최단 거리(간선 수)는 BFS로 구한다.
    • 미방문 정점마다 탐색을 새로 시작한 횟수가 연결 요소(그룹) 개수다.
    • DFS·BFS 모두 인접 리스트 기준 O(V + E) — 각 정점 한 번, 각 간선 최대 두 번.
